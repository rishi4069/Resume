# Rishi Ranjan — Senior Backend & Software Engineer Portfolio

A modern, high-performance static portfolio website engineered for Rishi Ranjan, specializing in Java, Spring Boot, Microservices, and Distributed Systems.

## Features
- **Obsidian Dark Theme**: Modern dark aesthetic with emerald accents (`#63e6be`), glassmorphic frosted navbar, and clean typography (`Space Grotesk`, `Inter`, `JetBrains Mono`).
- **Developer Touch**: Syntax-highlighted interactive terminal card showcasing real-world Spring Boot enterprise architecture.
- **Impact-Driven Experience**: Timeline detailing scale (20M+ residents served, 99.7% logic accuracy, 70+ production defects resolved, 270+ batch jobs converted).
- **Deep Project Case Studies**: Multi-tier e-commerce platform, phonic-to-sign language translator, and enterprise rule engines.
- **Interactive Features**: 
  - Dynamic scroll-spy navbar highlighting active sections.
  - Responsive mobile drawer navigation with backdrop blur.
  - One-click copy email to clipboard with floating toast notification.
  - Accessible semantic HTML5 and OpenGraph metadata.

## Structure
```
Resume/
├── index.html    # Core semantic HTML5 document
├── style.css     # Modern responsive stylesheet & CSS variables
├── script.js     # Lightweight vanilla JavaScript interactions
└── README.md     # Project documentation
```

## Running Locally
Simply open `index.html` in any modern web browser or serve via:
```bash
# Using Python
python -m http.server 8000
```
Then navigate to `http://localhost:8000`.
